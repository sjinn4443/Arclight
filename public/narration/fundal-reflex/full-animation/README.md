## Pronunciation guide

- **Arclight:** English “ARK-light” (`/ˈɑːk.laɪt/`); Spanish “ARK-lait”. Keep the brand name in English.
- **fundal reflex:** English “FUN-dəl REE-fleks”. Spanish narration uses the more natural phrase _reflejo del fondo de ojo_; _reflejo rojo_ is also common clinically.
- **retinoblastoma:** English “ret-ih-no-blas-TOH-muh”; Spanish “reh-tee-noh-blahs-TOH-mah”. This term is retained here for later scrolly narration, although it is not spoken in this animation draft.
- **Korean terms:** _fundal reflex_ is narrated as “안저 반사”, and _retinoblastoma_ as “망막모세포종”. Arclight remains the brand name and is pronounced “아크라이트”.

The audio is an AI-voice review draft and should receive clinical and native-speaker approval before publication. `script.json` is the source of truth for regeneration and later scrolly reuse.

## Rebuilding the media

Install the temporary speech and FFmpeg tooling, then run the generator from the repository root:

```powershell
python -m pip install --target tmp\fundal-narration-tools edge-tts imageio-ffmpeg
python scripts\generate-fundal-narration.py
```

The generator fingerprints every cue, enforces the 1.08× speed ceiling and 2 MB delivery-track limit, writes app-ready M4A/VTT files here, and keeps WAV masters, review MP4s and the QA report in `.codex-artifacts/fundal-reflex-narration/`.
