# Squint v1.1 gap list

Date: 23 July 2026

| Area                   | Gap                                                                                                                   | Resolution                                                                                                                                                                                                         |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Runtime                | Google Fonts CDN required                                                                                             | Removed remote links and preloaded the existing local Inter and Quicksand files.                                                                                                                                   |
| Session safety         | No deliberate way to abandon simulator changes                                                                        | Added a two-press New session action which restores the normal teaching scene and preserves the cup.                                                                                                               |
| Offline                | No manifest or scoped service worker                                                                                  | Added an app-scoped `squint-` cache and install metadata.                                                                                                                                                          |
| Contracts              | Parity harness existed but platform contracts did not                                                                 | Retained the passing parity harness and added runtime-locality, initial teaching-state, reset and PWA contracts.                                                                                                   |
| UI consistency         | Mixed typography and literal radii                                                                                    | Made Inter the UI face, retained Quicksand for the title, introduced a restrained radius hierarchy and styled reset as a secondary action. Existing anatomical shapes and pill controls keep intentional geometry. |
| Overlay accessibility  | Drawer, information and MCQ overlays did not consistently enter, contain or return focus                              | Added synchronised ARIA state, a visible drawer close control and contained focus with return to the opening app-bar control.                                                                                      |
| MCQ focus regression   | MCQ close scheduled focus return after clearing its target, causing a runtime error and leaving focus on the document | Captured the return target before clearing MCQ state and added browser-review assertions for open and close focus.                                                                                                 |
| Preset notice          | The active preset notice overlapped the Light control at `360 x 740`                                                  | Moved the notice below the Light control without changing the eye scene or card height.                                                                                                                            |
| Compact touch targets  | The three main switches, Advanced control, ambient switch and in-scene controls had small hit areas                   | Made each main tile clickable, widened Advanced to `44px`, expanded the ambient hit area and added invisible `44 x 44px` hit regions to compact in-scene controls.                                                 |
| Manual keyboard access | Diagnostic gaze and swinging light were pointer-only                                                                  | Added momentary arrow-key operation which uses the existing controller paths and returns to primary gaze or torch-off on release.                                                                                  |
| Cover announcement     | Visual cover state was not exposed to assistive technology                                                            | Synchronised `aria-pressed` with the existing cover state.                                                                                                                                                         |
| Update freshness       | Cached navigation could keep an open tab on an older app shell while online                                           | Changed navigation to network-first with the cached index retained as the offline fallback and bumped the app cache.                                                                                               |
| Help and memory        | Visible help and two memory statements described removed controls, a red title and Google Fonts                       | Updated the help version and wording, corrected the yellow title and recorded local fonts.                                                                                                                         |

The ocular alignment, motility, pupil and analysis rules were not changed. Cover, gaze and light controllers received accessibility-only input and state-announcement handling. Workflow order, outputs, assets, IDs and the blue/yellow accent remain intact. The initial normal output is an intentional simulator lesson state, not an unassessed patient record.
