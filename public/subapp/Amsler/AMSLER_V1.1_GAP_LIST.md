# Amsler v1.1 Gap List

Date: 24 July 2026

## Closed engineering gaps

- Removed normal-runtime Google Fonts and Font Awesome CDN dependencies.
- Pinned html2canvas 1.4.1 locally with its MIT licence.
- Added a reproducible source-to-bundle build and alignment check.
- Added semantic dialogs, keyboard close controls, drawer state, focus entry, focus containment and focus restoration.
- Added explicit eye-tab state, named tools, a named canvas and live result announcements.
- Added a two-step examination-only reset which retains teaching achievement.
- Added an app-scoped manifest and service worker with HTTP-only registration.
- Added Node built-in contracts for state, authored MCQs, runtime assets, ARIA targets, reset separation, Compute completion and bundle alignment.
- Completed lead desktop-browser review at `360 x 740`, including report, reset, focus, MCQ, offline reload and clean-console checks.
- Replaced viewport-dependent canvas-pixel percentages with a pure fixed-resolution normalised engine.
- Added explicit per-eye `Not assessed`, `No marks recorded` and marked states.
- Replaced stale computed summaries immediately when a drawing changes and kept Report fail-closed.
- Defined whole-grid, central-zone and outer-zone denominators explicitly.
- Counted the actual interior of closed Missing and Red mark regions while retaining open Line marks as strokes.
- Removed the geometry-based `wavy` versus `dark` inference from runtime output.
- Added seven direct engine tests for per-eye state, viewport invariance, zone denominators, closed regions, overlap union and malformed input.
- Replaced the patient letter with a local head-and-shoulders silhouette and aligned the app-bar information glyph to the fleet bare `i`.

## Preserved behaviour

- Red `#ff2a18` app identity and compact control geometry.
- RE and LE drawing, visual modes, responsive canvas geometry and pen-width control.
- Compute as the explicit completion action.
- Report content, WebP download and share behaviour.
- MCQ levels, scoring and achievement persistence.
- Direct-file launch through the generated classic bundle.

## Open external gates

- Independent clinical review and sign-off.
- Physical-device and constrained-device testing.
