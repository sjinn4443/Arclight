# Refract v1.1 UI gap list

Date: 23 July 2026

- Radii: replaced remaining hard-coded card, input, transpose and popup radii with the established token hierarchy.
- Spacing and alignment: preserved the compact one-page grid, current/objective/output order and existing measured field alignment.
- Typography: runtime now uses the local Inter and Quicksand files. Removed decorative italic treatment from the mode switch while retaining data-entry placeholder behaviour.
- Borders and shadows: retained restrained existing card and control treatments. The reset is a quiet secondary drawer action, with warning colour only during confirmation.
- Action hierarchy: transpose remains beside its existing label and New case sits in the secondary drawer, preventing competition with prescription entry.
- Icons: replaced the remote Font Awesome transpose glyph with a local character while preserving its accessible button label.
- Overlay focus: Quick guide and drawer focus now enter their visible controls, remain contained during keyboard navigation and return to the opening app-bar control when closed.

No wholesale redesign or accent change was made.
