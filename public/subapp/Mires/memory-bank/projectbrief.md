Newton is a focused training tool for Goldmann split-prism mire alignment and practical IOP estimation judgment.

Primary objective:

- Improve operator confidence in aligning mires to correct endpoint under realistic instability.

Secondary objectives:

- Build intuition for IOP ranges using variable and Newton case workflows.
- Reinforce core Goldmann principles with tiered MCQs.

Current learning structure:

- Simulator practice in two drawers:
  - `Variable IOP's`
  - `Newton IOP`
- MCQ tiers:
  - Primary
  - Intermediate
  - Advanced
