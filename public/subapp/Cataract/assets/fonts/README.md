# Local Fonts

This folder stores the app fonts so the teaching tool can run without loading Google Fonts at runtime.

- `inter-latin-400-800.woff2`: Inter UI font, Latin subset, variable weights 400-800.
- `quicksand-latin-700.woff2`: Quicksand title font, Latin subset, weight 700.

Source: Google Fonts. Both families are distributed under the SIL Open Font Licence.
