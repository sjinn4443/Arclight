# `vscode-alanui-launcher` Directory

This directory contains a custom Visual Studio Code extension designed to streamline the development workflow for the Arclight App.

## VSCode Extension (`vscode-alanui-launcher`)

This custom VSCode extension provides a convenient way to launch the Arclight App locally. It adds a status bar button that, when clicked, opens the application in a browser at `http://localhost:3000`.

## Installation and Usage

Refer to the `README.md` file within this directory for detailed instructions on how to install and use the `vscode-alanui-launcher` extension.
