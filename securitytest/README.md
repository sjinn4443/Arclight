# `securitytest` Directory

This directory contains scripts designed for testing the security configurations implemented in the Arclight application. These scripts help verify the effectiveness of measures such as CORS, CSRF, and rate limiting.

## Security Testing Scripts

- **`cors_tests.ps1`**: PowerShell script for testing Cross-Origin Resource Sharing (CORS) configurations.
- **`csrf_test.ps1`**: PowerShell script for testing Cross-Site Request Forgery (CSRF) protection.
- **`header_checks.ps1`**: PowerShell script for checking various security headers.
- **`rate_burst_test.ps1`**: PowerShell script for testing rate limiting with burst scenarios.
- **`rate_test_node.js`**: Node.js script for testing rate limiting functionality.
